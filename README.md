# Snakes - 多人連線貪吃蛇

一個基於 Web 技術的多人即時在線貪吃蛇遊戲。使用 HTML5 Canvas 與 Web Worker 進行平滑感渲染，Node.js + Express 作為伺服器，並透過 Socket.io 實現低延遲雙向即時通信。

## 遊戲簡介
這是經典貪吃蛇的多人競技升級版！玩家可在廣大地圖中穿梭、吞食各具特殊效果的食物與道具，並與其他玩家或 AI 蛇進行實時對抗。遊戲全面支援桌面端與行動端（內建虛擬搖桿與操作按鍵）。

## 技術棧
- 前端：HTML5 Canvas、JavaScript (ES6+)、Web Workers（狀態運算與插值）
- 後端：Node.js、Express
- 即時通信：Socket.io
- 構建工具：無（原生 JavaScript）

## 功能特色
1. 多人即時對抗：支援同地圖多人與 AI 蛇同場競技。
2. Web Worker 渲染優化：狀態計算交由 Worker 處理，確保遊戲流暢。
3. 多元道具機制：包含傳送蘋果、混亂蘑菇、彈射葡萄與隨機禮盒。
4. 跨平台支援：PC 鍵盤操作與手機端虛擬搖桿 + 香蕉加速鍵。
5. 即時資訊：內建 Ping 值、FPS 幅率與即時排行榜。

## 安裝與運行
【先決條件】
- Node.js (v14.0.0 或更高版本)
- npm (v6.0.0 或更高版本)

【安裝步驟】
1. 克隆倉庫：
   git clone https://github.com/coffeecat123/snakes.git
   cd snakes

2. 安裝依賴：
   npm install

3. 啟動伺服器：
   npm start
   (或執行：node server.js)

4. 開啟瀏覽器遊玩：
   - 本機：http://localhost:3000
   - 區網連線：http://<你的區域網路IP>:3000

## 遊戲操作
【桌面端 (PC)】
- W / A / S / D 或 方向鍵 ：控制移動方向
- Shift (按住) ：加速移動
- Q (按住) ：顯示即時排行榜
- 畫面左上角按鍵 ：flsc (全螢幕) / fps (態率顯示)

【行動端 (Mobile)】
- 螢幕左半部滑動 ：虛擬搖桿控制方向
- 螢幕右半部按住 ：香蕉圖示(🍌)加速
- 畫面左上角按鍵 ：flsc (全螢幕) / fps (幅率) / rank (排行榜)

## 道具與規則說明
【特殊道具】
1. 🍎 / X (傳送蘋果) ：得 +1 分，並傳送至標記點 X。
2. 🍄 / X (混亂毒菇) ：扣 -0.5 分，且 3 秒內操控方向顛倒（頭頂顯示 ?）。
3. 🍇 / X (彈射葡萄) ：扣 -3 分，並將葡萄朝碰撞反方向高速撞飛。
4. 🎁 (神秘禮盒) ：隨機獲得 -10 ~ +10 分。

【碰撞與成長】
- 得分越高，蛇的體型（半徑）越大、身體越長。
- 兩蛇頭部相撞時，半徑較大（分數較高）的一方會掠奪對方的分數。
